## 设计说明

- **风格**：编辑式优雅。象牙纸底 `#fbf9f6`、墨黑正文 `#17161a`、胭脂点缀 `#9e3b4e`，靠留白与 1px 细规则线建立秩序。
- **字体**：标题与数字用思源宋体（衬线），正文用系统无衬线（PingFang SC / 微软雅黑）。中文字体全量有 11MB，这里按页面实际用到的 1026 个字符裁剪成 **287KB / 291KB** 两个 woff2，自托管、不依赖 Google Fonts（境内访问更稳）。
- **响应式**：900px 与 640px 两个断点，作品集图片走 `srcset` 按屏幕密度选择。
- **可访问性**：跳转链接、`aria-current`、灯箱 Esc 关闭与焦点回收、`prefers-reduced-motion` 降级；关闭 JS 后内容与导航依然完整可读。

### 作品集清晰度

清晰度的硬上限是**源图分辨率**，不是 CSS。用「源像素 ÷ 设备像素」这个密度衡量（≥1 表示每个屏幕像素都有对应的源像素，不会被拉伸）：

| 场景 | 改进前（1600px 源） | 改进后（3840px 源） |
|---|---|---|
| 桌面 1440 @2x · 原始尺寸 | 0.57（发虚） | **1.36** |
| 桌面 1440 @2x · 放大 2.6x | 0.22（很虚） | 0.52 |
| 手机 390 @3x · 原始尺寸 | 1.47 | **3.54** |
| 手机 390 @3x · 放大 2.6x | 0.57（发虚） | **1.36** |

做法：
- 灯箱单独用 3840px 档。1600px 在 2x 屏桌面上连 1:1 都达不到，放大必然发虚。
- PDF 里的文字与形状是**真矢量**，提高渲染 DPI 是实打实增加细节，不是把位图拉大。
- **渐进加载**：先用页内已缓存的中等档秒开，高清档解码完成后再顶上，开灯箱不会白屏。
- 缩放上限从 6x 收到 4x —— 6x 在任何分辨率下都只是拉伸。
- 不预取相邻页的高清档（每次滑动会悄悄多下 400KB），改为按需加载。

桌面视网膜屏放到 2.6x 时密度只有 0.52：此时显示宽度约 3600 CSS px = 7300 设备像素，任何体积可控的源图都填不满。要彻底解决需要 6000px 以上的档（体积翻倍到 30MB+），当前取的是体积与清晰度的平衡点。

## 移动端 Safari 适配

针对 iPhone 逐项处理过的问题：

| 问题 | 处理方式 |
|---|---|
| 刘海 / 圆角 / Home 指示条遮挡 | `viewport-fit=cover` + 全站 `env(safe-area-inset-*)`；吸顶导航底色盖住刘海区，内容靠内边距避开；页脚底部留出指示条高度 |
| 地址栏收起/展开导致首屏高度跳动 | 首屏留白改用 `svh`（可见视口高度），`vh` 作为旧浏览器回退 |
| 点锚点后标题被吸顶栏压住 | 锚点偏移用 JS 实测吸顶元素高度写入 `--header-total` / `--pf-nav-h`，不写死常数 |
| iOS 把手机号自动变成拨号链接，绕过打码按钮 | `format-detection: telephone=no` |
| 点按有 300ms 延迟、出现灰色闪块 | `touch-action: manipulation` + `-webkit-tap-highlight-color: transparent`，反馈改由 `:active` 承担 |
| 点完还留着 hover 态 | `@media (hover: none)` 里重置全部悬停样式 |
| 触摸端可点区域偏小 | `@media (pointer: coarse)` 下把导航、标签、按钮放大到 44px 以上（Apple HIG 建议值） |
| 橡皮筋回弹露出白底 | `overscroll-behavior-y: none` |
| 作品集细节看不清、不能翻页 | 灯箱支持**双指缩放、双击放大、放大后拖动平移、左右滑动翻页、下滑关闭**；打开时锁住背景滚动并在关闭后精确还原滚动位置 |
| 横屏时内容被推到折叠线以下 | `landscape` + `max-height: 520px` 下收紧首屏留白与头像宽度 |

手感细节：滑动时图片跟手位移（超过 16% 屏宽即翻页，否则回弹）；灯箱渐进加载，翻页立刻显示中等档再自动换成高清档；放大状态下滑动是平移而不会误关闭。

## 重新生成资源

改过页面文案后，字体子集需要重新生成（否则新出现的汉字会回退到系统字体）：

```bash
pip install pymupdf pillow fonttools brotli
# 思源宋体 OTF 放在 %TEMP%\hanserif\，或用 SMIND_FONT_SRC 指定目录
python tools/build-assets.py
```

改完文案可以用这个脚本确认没有漏字（漏字会让该字回退到系统字体，句中字体会变）：

```bash
python tools/check-font-coverage.py
```

作品集图片由作品集 PDF 渲染而来，如需更新：

```bash
python tools/render-portfolio.py   # 需要把作品集 PDF 放回本目录
```

## 本地预览

静态站点，任意静态服务器即可（直接双击 `index.html` 也能看，但 `srcset` 与字体在 `file://` 下行为不同，建议起服务）：

```bash
python -m http.server 8080
# 然后打开 http://localhost:8080/
```

## 部署

推送到 `main` 分支后，GitHub Pages 会自动构建并发布：

```bash
git add -A
git commit -m "更新网站内容"
git push
```

站点来源配置：仓库 `Settings → Pages → Source: Deploy from a branch → main / (root)`。
